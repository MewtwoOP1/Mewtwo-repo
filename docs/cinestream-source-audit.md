## Ranking

CineStream ranks every discovered source with a weighted score and **reorders** the list — it never removes a source.

Two profiles share the same scoring utilities:

| Factor | Movie weight | Anime weight |
|---|---:|---:|
| Playability (known format, https, measured provider + extractor success) | 34 | 32 |
| Resolution | 20 | 14 |
| Video format (hls / mp4 compatibility) | 12 | 10 |
| Provider reliability | 12 | 6 |
| Extractor reliability | 8 | 4 |
| Audio quality (multi-audio, known language) | 6 | 6 |
| Language preference (sub/dub, audio code) | 0 | 16 |
| Resolution speed | 4 | 3 |
| Codec / source-format hints | 2 | 2 |
| Metadata completeness | 2 | 2 |
| Subtitle availability | 0 | 3 |

Quality labels are normalised: `2160p` / `4K` / `UHD` → 2160, `1440p` → 1440, `1080p` / `FHD` → 1080, `720p` / `HD` → 720, `576p`, `480p`, `360p`, unknown → neutral. An advertised label is **not** treated as proof of quality: playability still dominates the score, so a verified 1080p source outranks a broken 4K link.

Reliability comes from real extraction attempts and decays with a six-hour half-life, so one outage cannot permanently penalise a provider and an old failure cannot permanently exclude one. Reliability only affects the **order** — it never removes a provider from the run or a source from the list.

Ordering modes are configurable: **Source order** (best / quality / speed / reliable), **Preferred anime audio** (any / sub / dub) and **Preferred audio language**. Equal scores keep their discovery order, so the list stays predictable.## Verification

**Zangetsu playback is UNVERIFIED for every provider.** This environment has no Android runtime, no `adb`, no display and no Zangetsu app, so the real player could not be exercised. Per the acceptance rule ("a successful build is not proof of working playback"), no playback PASS is claimed anywhere in this document.

What *is* verified is that every provider, when it resolves, emits a complete source object: URL, container, quality, provider identity, server identity, the `Referer` / `Origin` / `User-Agent` headers the host requires, cookies where the host needs them, and any subtitle tracks. The automated suites assert that shape for every provider.

Host reachability and the API contracts were verified live over the network. Verification date: see the git history of this file. Third-party hosts change domains and go down; the statuses here describe one point in time and are not a promise of permanent availability.
